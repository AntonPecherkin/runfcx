# Plan 3: Microsite, agent.md, Upstream PRs, Submission — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The tutorial microsite that judges and testers read first, an `agent.md` an AI agent can follow end to end, upstream doc PRs, and a ready-to-post submission.

**Architecture:** Plain static site in `site/` (HTML + one CSS file + small vanilla JS, no framework, no build step), served by GitHub Pages from a workflow. A Node script `site/tools/check.mjs` is the test suite: it enforces the writing rules, structure, links, accessibility basics and that every code snippet on the site matches the real source in `cli/src/` (snippets are pulled from `// @snippet <name>` markers by `site/tools/snippets.mjs`). Real numbers and terminal output come from `docs/runs/*.md` via `site/data/runs.json`; nothing on the site is typed by hand when a run recorded it.

**Tech Stack:** HTML5, CSS custom properties (light/dark), vanilla JS (ES2020, no deps), inline SVG. Node ≥ 20 for the tools, `node:test` for the checker's own tests. GitHub Pages + `actions/deploy-pages`.

**Spec:** `docs/superpowers/specs/2026-10-18-farcaster-3-commands-design.md` (sections 8, 9, 10; section 3 facts; section 12 timeline)

## Global Constraints

- Static, GitHub Pages, mobile + desktop, light + dark, no heavy framework. No external JS. Fonts: system stack.
- One accent color: Farcaster purple `#855DCD` (dark mode `#A88BE0`). Clean typography.
- Writing rules (spec §9), enforced by `check.mjs`:
  - Short sentences. What to do first, then why in one or two lines.
  - Banned: "not X, but Y" / "A, not B" contrasts; "seamless", "robust", "leverage", "delve", "unlock", "powerful", "journey", "dive in"; em-dash chains; rule-of-three lists; hype emoji; recap paragraphs.
  - Real terminal output, real numbers. Human pass on every page.
- Quickstart is exactly: `npx fcx-cli provision --ttl 8h`, `npx fcx-cli node`, `npx fcx-cli login --wallet`.
- Placeholders `{{OWNER}}` and `{{SITE}}` are filled from `site/site.json` at deploy time; until the owner is chosen they stay in source and `check.mjs --release` fails on them.
- Agent hard rules (spec §8): never ask for or handle seed phrases or the Hetzner token in chat; never post, follow or like without the human's OK; always state cost and TTL.
- Nothing is published, pushed, posted or PR'd without the user's explicit OK at that step.
- Compute in the tutorial: Hetzner (scripted, `--ttl`) and "I have a server" (`--host`, with the Vultr notes from run 1).

## Review Focus

1. **Phone width (360–390 px).** Expected: no horizontal page scroll; code blocks scroll inside themselves; diagrams scale. → Task 1 check (`pre` overflow rule, SVG `viewBox` without fixed width) + Task 8 manual screenshots at 375 px.
2. **Dark mode.** Expected: every color comes from a token; SVGs use `currentColor`/tokens so lines stay visible. → Task 1 check (no hex colors outside `:root` blocks in CSS and SVG).
3. **A snippet on the site drifts from the code it quotes.** Expected: `check.mjs` fails with the snippet name. → Task 2 test `detects drift`.
4. **An agent following `agent.md` hits a state the doc doesn't cover** (node still syncing at login, SSH blocked, disk full, shard from genesis). Expected: the error table has a row for every `fcx status` phase and every user-facing error string in `cli/src`. → Task 5 check `agent.md covers every phase and error`.
5. **Reduced motion / no JS.** Expected: animations respect `prefers-reduced-motion`; with JS off every step of "life of a cast" is still readable as a list. → Task 4 check + Task 8 manual pass.

```js
// The site's writing and structure rules, as code. Each check returns a list of problems.
const WORDS = ["seamless", "robust", "leverage", "delve", "unlock", "powerful", "journey", "dive in"];
const RECAP = /\b(in summary|to sum up|in conclusion|to recap|all in all)\b/i;
const NOT_BUT = /\bnot (an? |the )?[\w-]+( [\w-]+)?, but\b/i;          // "not a server, but a relay"
const X_NOT_Y = /\b[\w-]+, not [\w-]+\.?/i;                              // "Keys, not passwords."
const EMDASH_CHAIN = /—[^—\n]{0,40}—/;
const HYPE = /[\u{1F525}\u{1F680}\u{2728}\u{1F389}\u{1F4AF}\u{1F64C}\u{26A1}]/u;

const visible = (html) => html.replace(/<(script|style|pre|code)[\s\S]*?<\/\1>/g, " ").replace(/<[^>]+>/g, " ");

export function bannedPhrases(text) {
  const t = visible(text), out = [];
  for (const w of WORDS) if (new RegExp(`\\b${w}\\b`, "i").test(t)) out.push(`banned word "${w}"`);
  if (NOT_BUT.test(t)) out.push(`"not X, but Y" contrast: ${t.match(NOT_BUT)[0]}`);
  if (X_NOT_Y.test(t)) out.push(`"A, not B" contrast: ${t.match(X_NOT_Y)[0]}`);
  if (EMDASH_CHAIN.test(t)) out.push("em-dash chain");
  if (HYPE.test(t)) out.push("hype emoji");
  if (RECAP.test(t)) out.push(`recap phrase: ${t.match(RECAP)[0]}`);
  return out;
}

export function structure(html, file) {
  const out = [], need = (re, what) => { if (!re.test(html)) out.push(`${file}: missing ${what}`); };
  need(/<html[^>]+lang="/, "<html lang>");
  need(/<meta name="viewport" content="width=device-width/, "viewport meta");
  need(/<title>[^<]+<\/title>/, "<title>");
  need(/<main[\s>]/, "<main>");
  for (const img of html.match(/<img\b[^>]*>/g) ?? []) if (!/\balt="/.test(img)) out.push(`${file}: img without alt: ${img}`);
  for (const s of html.match(/<script\b[^>]*\bsrc="https?:[^"]*"/g) ?? []) out.push(`${file}: external script ${s}`);
  return out;
}

export function cssTokens(css) {
  const out = [];
  const outside = css.replace(/(:root|\[data-theme[^\]]*\])[^{]*\{[^}]*\}/g, "").replace(/@media[^{]*\{\s*(:root|\[data-theme[^\]]*\])[^{]*\{[^}]*\}\s*\}/g, "");
  for (const hex of outside.match(/#[0-9a-fA-F]{3,8}\b/g) ?? []) out.push(`color ${hex} outside the token blocks`);
  if (!/pre\s*\{[^}]*overflow-x:\s*auto/.test(css)) out.push("pre needs overflow-x:auto (phones)");
  return out;
}

export function links(files) {
  const ids = new Map([...files].map(([f, h]) => [f, new Set([...h.matchAll(/\bid="([^"]+)"/g)].map((m) => m[1]))]));
  const out = [];
  for (const [f, h] of files) for (const [, href] of h.matchAll(/href="([^"]*)"/g)) {
    if (!href || href.includes(":")) continue; // http:, https:, mailto: are external
    const [page, hash] = href.split("#");
    const target = page || f;
    if (page && !files.has(page)) { out.push(`${f}: broken link ${href}`); continue; }
    if (hash && !ids.get(target)?.has(hash)) out.push(`${f}: broken link ${href}`);
  }
  return out;
}
```

- [ ] **Step 3: Implement `snippets.mjs`**

```js
// Code on the site is copied from cli/src at build time, so the tutorial can't drift from the code it explains.
import { readFileSync, readdirSync, writeFileSync } from "node:fs";
import { join } from "node:path";

const esc = (s) => s.replace(/&/g, "&amp;").replace(/</g, "&lt;").replace(/>/g, "&gt;").replace(/"/g, "&quot;");

export function extract(source) {
  const out = new Map();
  for (const m of source.matchAll(/^[ \t]*\/\/ @snippet ([\w-]+)\n([\s\S]*?)^[ \t]*\/\/ @end/gm)) {
    const lines = m[2].replace(/\n$/, "").split("\n");
    const pad = Math.min(...lines.filter((l) => l.trim()).map((l) => l.match(/^ */)[0].length));
    out.set(m[1], lines.map((l) => l.slice(pad)).join("\n"));
  }
  return out;
}
export const inject = (html, s) => html.replace(/(<pre data-snippet="([\w-]+)">)[\s\S]*?(<\/pre>)/g,
  (all, open, name, close) => (s.has(name) ? open + esc(s.get(name)) + close : all));
export const drift = (html, s) => [...html.matchAll(/<pre data-snippet="([\w-]+)">([\s\S]*?)<\/pre>/g)]
  .filter(([, name, body]) => !s.has(name) || body !== esc(s.get(name))).map(([, name]) => name);

export function loadAll(srcDir) {
  const all = new Map();
  for (const f of readdirSync(srcDir)) if (f.endsWith(".ts")) for (const [k, v] of extract(readFileSync(join(srcDir, f), "utf8"))) all.set(k, v);
  return all;
}
// node site/tools/snippets.mjs  → rewrites every site/*.html in place
if (import.meta.url === `file://${process.argv[1]}`) {
  const root = new URL("../..", import.meta.url).pathname, s = loadAll(join(root, "cli/src/client"));
  for (const f of readdirSync(join(root, "site"))) if (f.endsWith(".html")) {
    const p = join(root, "site", f); writeFileSync(p, inject(readFileSync(p, "utf8"), s));
  }
}
```

// docs/runs/*.md → site/data/runs.json. The site only shows numbers a run recorded.
import { readFileSync, writeFileSync, readdirSync } from "node:fs";
import { join } from "node:path";

export function parseRun(md) {
  const n = md.match(/```fcx-numbers\n([\s\S]*?)```/);
  if (!n) throw new Error("no fcx-numbers block");
  const numbers = Object.fromEntries(n[1].trim().split(/\s+/).map((kv) => kv.split("="))
    .map(([k, v]) => [k, /^-?\d+(\.\d+)?$/.test(v) ? Number(v) : v]));
  const terminal = Object.fromEntries([...md.matchAll(/```fcx-term ([\w-]+)\n([\s\S]*?)\n```/g)].map((m) => [m[1], m[2]]));
  return { numbers, terminal };
}
if (import.meta.url === `file://${process.argv[1]}`) {
  const root = new URL("../..", import.meta.url).pathname, out = { terminal: {} };
  for (const f of readdirSync(join(root, "docs/runs")).filter((f) => f.endsWith(".md")).sort()) {
    const r = parseRun(readFileSync(join(root, "docs/runs", f), "utf8"));
    out[f.replace(".md", "").replace("-", "")] = r.numbers; Object.assign(out.terminal, r.terminal);
  }
  writeFileSync(join(root, "site/data/runs.json"), JSON.stringify(out, null, 2) + "\n");
}

export function agentCoverage(md, phases, errors) {
  const out = [];
  for (const p of phases) if (!new RegExp(`\\|\\s*${p}\\s*\\|`).test(md)) out.push(`agent.md: phase ${p} not covered`);

  return out;
}
