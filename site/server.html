Renting the server

You need it for a few hours. Pick one of three ways.

Any provider, same spec
  • 4 vCPU, 16 GB RAM
  • 2 TB disk. The snapshot restore peaks near 1.6 TB, so 1.5 TB runs out.
  • Ubuntu 24.04, billed by the hour

Hetzner · fully scripted

fcx creates the server, disk and firewall, and deletes them all when the timer runs out.

  1. Create a new project in the Hetzner Cloud console. Use it only for fcx: the token can delete anything in its project.
  2. In that project: Security → API tokens → Generate, with Read & Write.
  3. Copy the token, then save it without pasting it anywhere else: 
    mkdir -p ~/.config/fcx
pbpaste > ~/.config/fcx/hcloud-token   # Linux: xclip -o > …
chmod 600 ~/.config/fcx/hcloud-token
  4. Run npx fcx-cli provision --ttl 8h

Vultr · by hand, with free credit

New accounts get $300 of credit through our referral link. That covers many runs. You click the server together yourself, then hand it to fcx.

  1. Sign up, then open a support ticket: "Please raise my block storage limit to 2500 GB." New accounts can't create a 2 TB disk until they do.
  2. Make the SSH key fcx uses, and add the public half under Account → SSH Keys: 
    mkdir -p ~/.fcx && ssh-keygen -t ed25519 -N "" -C fcx -f ~/.fcx/ssh_ed25519
cat ~/.fcx/ssh_ed25519.pub
  3. Network → Firewall: allow SSH (22) from your IP only, and UDP 3382 from anywhere. Nothing else.
  4. Storage → Block Storage: a bootable 2000 GB volume with Ubuntu 24.04.
  5. Deploy → Dedicated CPU → vx1-g-4c-16g, in the same location, with that volume, your key and your firewall. Turn off backups.
  6. Run npx fcx-cli provision --host root@YOUR_IP --data-dir /mnt/fcx

When you're done: destroy the server and delete the block storage. A stopped server still bills.

Your own box

Any Ubuntu or Debian machine with the spec above. Put ~/.fcx/ssh_ed25519.pub in root's authorized_keys, open UDP 3382, then:

npx fcx-cli provision --host root@YOUR_IP
