Keep it running

For a node that stays up. Start it with --keep or on your own box.

Upgrades

runfcx installs upstream's weekly auto-upgrade. It restarts the node only when there is a new release.

ssh -i ~/.fcx/ssh_ed25519 root@YOUR_IP cat /etc/cron.d/fcx-autoupgrade

Logs

ssh -i ~/.fcx/ssh_ed25519 root@YOUR_IP \
  'cd /root/snapchain && docker compose logs -f --tail 50 snapchain'

Dashboard

ssh -i ~/.fcx/ssh_ed25519 -N -L 3000:127.0.0.1:3000 root@YOUR_IP

Then open http://localhost:3000.

Restart

ssh -i ~/.fcx/ssh_ed25519 root@YOUR_IP 'cd /root/snapchain && ./snapchain.sh restart'
